Unitree Go2 Sim-to-Real Quadruped Locomotion

Genesis PPO Unitree Go2 Domain Randomization Sim-to-Real CycloneDDS
go2_sim2real ↗
Read full write-up & code ↗

Trained an asymmetric actor-critic locomotion policy across 4,096 parallel environments in Genesis simulator with aggressive domain randomization. Transferred zero-shot to the physical Unitree Go2 via low-level CycloneDDS, validating stable standing, push recovery, and blind omnidirectional walking.

Project Overview & Motivation

Reinforcement learning locomotion policy trained in Genesis simulator and deployed zero-shot onto the physical Unitree Go2 quadruped. Hardware validation demonstrated stable standing, push recovery, and blind omnidirectional walking.

System Architecture & Methodology

Asymmetric actor-critic (PPO via rsl_rl) trained across 4,096 parallel environments in Genesis with aggressive domain randomization (mass, friction, pushes, actuator PD gains). Commands stream directly over low-level CycloneDDS at 500 Hz.

Technical Specifications & Stack

  • Hardware: Unitree Go2 Quadruped (12 actuated DOF)
  • Interface: Unitree SDK 2 + CycloneDDS (500 Hz LowCmd)
  • Simulation: Genesis Simulator (4,096 parallel envs)
  • Policy: Asymmetric Actor-Critic (PPO via rsl_rl)
