Physics-Informed Neural Networks (PINNs)

SciML PyTorch Differential Equations Streamlit PINNs
GitHub Repository ↗
GitHub ↗

Deep learning framework for solving arbitrary non-linear ODEs and PDEs without labeled data, validated against the 1D heat equation. Includes an interactive Streamlit application supporting user-defined equations and 3D solution visualization.

Project Overview & Motivation

A scientific machine learning research tool for solving arbitrary ordinary and partial differential equations (ODEs and PDEs) without requiring labeled solution datasets. The network learns by enforcing governing physical differential equations directly within its loss function.

System Architecture & Methodology

Constructed deep fully-connected networks with automatic differentiation (Autograd) computing higher-order partial derivatives. The composite loss enforces initial conditions, boundary conditions, and differential operator residuals. Deployed within an interactive Streamlit application.

Technical Specifications & Stack

  • Framework: PyTorch with automatic differentiation
  • Web Interface: Streamlit with Plotly 3D visualization
  • Tested Equations: 1D Heat Equation, Wave Equation, Harmonic Oscillators
