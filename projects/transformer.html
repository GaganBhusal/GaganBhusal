English to Nepali Machine Translation with Custom Transformer

PyTorch Transformers NLP Attention Machine Translation
GitHub Repository ↗
GitHub ↗

Built an encoder-decoder Transformer from scratch in PyTorch. Hand-coded multi-head self-attention, positional embeddings, causal masking, and evaluated translation performance from English to Nepali with BLEU and chrF scoring.

Project Overview & Motivation

A pure PyTorch implementation of the full encoder-decoder Transformer architecture ('Attention Is All You Need') hand-coded from scratch without using PyTorch's high-level `nn.Transformer` or pre-built attention blocks.

System Architecture & Methodology

Implemented scaled dot-product attention, multi-head attention with projection matrices, positional encodings, cross-attention in the decoder, and causal future masking. Includes custom Byte-Pair Encoding (BPE) tokenization.

Technical Specifications & Stack

  • Framework: PyTorch
  • Components: Multi-Head Attention, Cross-Attention, Positional Encoding
