Open-Source 8-DOF Quadruped Robot

Embedded Robotics Inverse Kinematics Arduino ESP32 Quadruped Robot
GitHub Repository ↗
GitHub ↗

Co-engineered an open-source 8-DOF quadruped robot. Implemented inverse kinematics on an Arduino for real time leg trajectory planning and control, and deployed a custom on-device wake-word model on an ESP-32 for voice command triggers.

Project Overview & Motivation

An open-source, low-cost 8-DOF quadruped robot co-developed at Third World Nerd.

System Architecture & Methodology

Designed a 3D-printable modular chassis housing 8 micro-servos (2 DOF per leg: hip and knee pitch). Implemented trigonometric inverse kinematics running closed-loop on an Arduino micro-controller to generate trot, crawl, and pitch/roll stabilizing gaits. Integrated an ESP32 companion chip executing a quantized wake-word detector.

Technical Specifications & Stack

  • Microcontrollers: Arduino Nano (Kinematics) + ESP-32 (Audio & ML)
  • Kinematics: Closed 2D inverse kinematics
  • Mechanics: 3D printed chassis, metal-gear micro servos
