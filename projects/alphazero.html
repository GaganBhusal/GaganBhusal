AlphaZero from Scratch for Connect-4 Agent

PyTorch Deep RL MCTS Self-Play Connect4 ResNet

PyTorch implementation of DeepMind's AlphaZero algorithm for two-player Connect-4. Uses Monte Carlo Tree Search (MCTS), a residual policy value neural network, and self-play data generation without human domain knowledge. Outperformed depth-10 Minimax agents.

Project Overview & Motivation

A clean PyTorch implementation of DeepMind's AlphaZero algorithm built from first scratch for two player zero sum perfect information board games (here for Connect-4). The system learns from zero prior knowledge strictly through Monte Carlo Tree Search (MCTS) and self-play data generation.

System Architecture & Methodology

Built with an asymmetric MCTS engine utilizing the PUCT (Polynomial Upper Confidence Trees) exploration formula. Features a shared deep Residual Convolutional Neural Network (ResNet) trunk with two output heads: a policy head predicting move probability distributions, and a value head predicting expected game outcomes in [-1, 1]. Self-play incorporates Dirichlet noise at the search root to encourage exploration.

Benchmark Against Depth-10 Minimax

Validated the trained AlphaZero model on Connect4 against a Minimax agent equipped with alpha-beta pruning up to search depth 10. AlphaZero achieved a 100% win rate against the benchmark after self-play training, demonstrating superhuman tactical depth without hardcoded heuristics.

Technical Specifications & Stack

  • Framework: PyTorch
  • Neural Architecture: Residual Network (ResNet) with dual policy/value heads
  • Search Engine: Monte Carlo Tree Search (MCTS)
  • Environment: Connect4
