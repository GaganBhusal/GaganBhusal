# Gagan Bhusal — Robotics & ML Portfolio

Personal portfolio website of **Gagan Bhusal**, showcasing robotics, sim-to-real reinforcement learning, humanoid locomotion, and edge intelligence projects.

## Featured Work
- **Unitree Go2 Sim-to-Real Locomotion**: Blind omnidirectional locomotion policy trained with PPO in Genesis simulator and deployed to real Unitree Go2 hardware.
- **Unitree G1 Humanoid Retargeting**: Motion retargeting and RL policy pipeline for humanoid bipedal locomotion.
- **AlphaZero Connect4**: Monte Carlo Tree Search (MCTS) paired with dual-headed policy/value ResNet for self-play RL.
- **Ghost-Net**: Ultra-lightweight acoustic sensor neural network for low-power edge detection.
- **Satellite Super-Resolution**: Modified SRCNN and ESRGAN for multi-spectral satellite imagery enhancement.
- **PINNs**: Physics-Informed Neural Networks solving Burgers' and 2D Navier-Stokes equations without discretized meshes.
- **STEM Quadruped**: Analytical inverse kinematics trajectory planning on Arduino with on-device wake-word detection on ESP32.
- **Machine Translation**: Custom Transformer trained from scratch for English-to-Nepali translation.

## Stack
- Pure HTML5, CSS3, Vanilla JavaScript (zero heavy runtime dependencies, high performance).
